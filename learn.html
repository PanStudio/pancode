PanCode / Tutorials

Learn PanCode
on a real repository.

Each guide is one task on a repository you know, with the commands to run and what you should see. Pick the path that fits you, or open one guide.

You already use a coding agent

Keep your agent and put the harness around it. By the end you can check a change against the tests you name, hand bounded work to the agents you already use, and leave a run unattended within limits.

Path 2 / Science and HPC

You write research code and run it on a cluster

For research code, where a wrong number matters. By the end you can follow a numerical fix to recorded verification, keep a speed-up only when a measurement proves it, and coordinate workers on other machines over SSH.

  1. 01Your first session with PanCode5 min
  2. 02A numerical change, checked with PanCode5 min
  3. 03Run a research campaign and a blind arena7 min
  4. 04Work from a laptop with remote workers11 min

Path 3 / Local models

You run your own models

No account and no key. By the end you can choose models for conversation and for delegated work, read what each session cost, carry a long task through a handoff, and compare your models blind.

  2. 02Choose a model for your project6 min

  4. 04Keep a long coding task on track4 min
