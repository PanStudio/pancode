PanHub

Skills, plugins, extensions and built-in servers for PanCode, each pinned by the SHA-256 of its whole tree. These are the packs listed in the index bundled with PanCode v.

How packs and tiers work

A pack has one kind. A skill is written instructions the agent loads when a task needs them. A plugin carries several skills, prompts, agents or playbooks, and may declare MCP servers that stay untrusted until you trust them. An extension is code that runs in its own process and installs only after you review what it may do. Nothing here is installed automatically.

A skill, plugin or extension installs with the command on its row. It installs for your user by default; add --project to install it into the current project, or --dry-run to see the plan first. In the terminal, /hub browses the same packs.

A server is an MCP server built into PanCode, so there is nothing to install. Its row's command does something else: it starts that server for another agent host, such as an MCP client you already use, and takes neither --project nor --dry-run.
