PanHub

Installable packs of skills, plugins and extensions, each pinned by the SHA-256 of its whole tree. These are the 44 packs bundled with PanCode v0.9.0.

Ships in
pancode v0.9.0
Command
pancode hub
Packs
44

A pack has one kind. A skill is written instructions the agent loads when a task needs them. A plugin carries several skills, prompts, agents or playbooks, and may declare MCP servers that stay untrusted until you trust them. An extension is code that runs in its own process and installs only after you review what it may do. Nothing here is installed automatically.

Install a pack with the command on its row. It installs for your user by default; add --project to install it into the current project, or --dry-run to see the plan first. In the terminal, /hub browses the same packs.

Tiers

TierWhich packsInstalls as
coreFirst-party packs, published by pancode from hub/packs/.trusted
verifiedCommunity packs that passed the full review, with a licence on the allowlist.trusted
listedCommunity packs with a valid row, a reachable commit and a matching digest.foreign: their skills and prompts load only while you trust project imports.

A listing at any tier is not an endorsement. The PanHub guide covers scopes, updates, revocation and how a community pack enters the index.
