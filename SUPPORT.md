# Getting help with PanCode

- **Questions about installing or using PanCode:** `/report question`, or open a [question](https://github.com/akougkas/pancode/issues/new?template=question.yml) issue. No question is too basic.
- **Something went wrong:** run `/report bug` inside PanCode, or `pancode report bug` in a shell. It drafts the report, masks paths, host names and secrets, and shows you the exact text before anything is sent. You can also open a [bug report](https://github.com/akougkas/pancode/issues/new/choose) by hand.
- **A feature you want:** `/report feature`, or a [feature request](https://github.com/akougkas/pancode/issues/new/choose).
- **How a model, cluster or terminal worked:** open a [question](https://github.com/akougkas/pancode/issues/new?template=question.yml) issue and say what you ran.
- **A security problem:** follow [SECURITY.md](SECURITY.md) and report it privately, never in a public issue.

`pancode doctor` checks an installation and names the fix for most setup problems; the [guides](docs/guide/) cover installation, configuration and every command.

To work on PanCode itself, read [CONTRIBUTING.md](CONTRIBUTING.md).
